# 🌐 웹 화면 사용법

`STEP3_START.bat` 으로 웹이 열린 후, **무엇을 클릭하면 되는지** + **보안 안전한지** 정리.

---

## 🔒 보안 결론

- 외부(인터넷)에서 해킹? **❌ 불가능** (공유기 NAT)
- 같은 와이파이의 다른 사람? **❌ 차단됨** (127.0.0.1 only)
- 비밀번호 없어도? **OK** (본인 PC만 접근 가능)
- 다른 사람과 공유? `BETA_FLOW.md` 의 "다른 사람에게 공유" 참고

---

## 🚀 첫 사용 — 5분 워크플로우

1. 브라우저에서 자동 열림 (`http://127.0.0.1:8501`)
2. 왼쪽 사이드바에서 **🚀 시작 가이드** 클릭 → 3분 사용법 읽기
3. **📥 Upload** → 첫 자료 올리기 (PDF/TXT 1개 + 제목 + 종류)
4. **📚 Library** → 방금 올린 자료 선택 → 체크리스트 4개 → **'🟢 검색에 공개하기'**
5. **🔎 Search** → 예시 질문 클릭 또는 직접 입력 → 답변 + 출처 확인

---

## 📑 5개 페이지

| 페이지 | 역할 | 언제 클릭? |
|---|---|---|
| 🚀 **시작 가이드** | 사용법 + FAQ | 처음 1번만 |
| 📚 **Library** | 자료 검토 + 공개 결정 | 자료 올린 후 |
| 📥 **Upload** | 새 자료 올리기 | 새 자료 생길 때마다 |
| 🔎 **Search** | 질문하고 답 받기 | 매일 |
| 📊 **Status** | 통계 확인 | 가끔 |

## 💡 자주 만나는 흐름

### "자료를 올렸는데 검색에 안 나와요"
→ 정상. 자료는 처음에 **🟡 임시(Draft)** 상태입니다.
**📚 Library** → 자료 선택 → **'✅ 검증/공개' 탭** → 체크리스트 4개 → **'🟢 검색에 공개하기'**

### "큰 수정을 했어요"
→ 외부 편집기(워드 등)에서 수정 → **📥 Upload**에 같은 자료 다시 올리기 → 자동으로 v2 생성

### "잘못 공개했어요"
→ **📚 Library** → 자료 선택 → **'✅ 검증/공개' 탭** → **'🗄 아카이브'** 버튼

### "공개 처리가 너무 오래 걸려요"
→ **첫 공개만** 5~10분 (AI 임베딩 모델 1.3GB 자동 다운로드).
→ 두 번째부터는 30초 이내.

## 🌍 다른 사람과 공유

본인 PC에서만 동작합니다. 가족·교회 사무실(같은 와이파이)과 공유하려면:

1. `.env` 파일을 메모장으로 열고:
   ```
   APP_PASSWORD=강한비밀번호
   ```
2. `STEP3_START.bat` 메모장으로 열기 → `127.0.0.1` 을 `0.0.0.0`으로 모두 변경 (4곳)
3. `ipconfig` → 본인 PC의 IP 확인 (예: 192.168.0.5)
4. 다른 사람에게 `http://192.168.0.5:8501` + 비밀번호 알려주기

**인터넷 공개**는 별도 배포 작업 필요 (`deploy.md` 참고).

## 🆘 막혔을 때

| 증상 | 해결 |
|---|---|
| `API 연결 실패` | `Gospel API` 검정창 확인. 닫혔으면 STEP3 재실행 |
| 답변이 영어/이상함 | 같은 질문 다시. 또는 자료가 부족 (자료 더 올리기) |
| 처음 답변 1-2분 | 정상. 재순위 모델(600MB) 1회 다운로드 |
| Gemini 한도 초과 | 잠시 후 재시도 또는 새 API key |
| 그 외 모든 에러 | `DIAGNOSE.bat` 실행 → `diagnose_result.txt` 확인 |
