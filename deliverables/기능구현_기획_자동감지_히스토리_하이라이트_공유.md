## A. 모바일 언어 자동감지 (소규모)

**현재**: `mobile/utils/state.js:60` `targetLang: 'zh'` 고정 → 중국어 질문이 아니어도 중국어 답변 강제.

**변경**:

1. `state.js:60`: `targetLang: 'zh'` → `localStorage.getItem('gospel_lang') || 'auto'` (명시 토글은 유지, 기본은 자동).
2. `screens/index.js:1051`: `AppState.get('targetLang') || 'zh'` → `|| 'auto'`.
3. `services/index.js:598`: 기본 파라미터 `targetLang = 'zh'` → `= 'auto'`.

→ 백엔드가 이미 `target_lang="auto"` 를 `detect_language()` 로 해석(직전 턴 구현).

## B. 채팅 히스토리 (목록/이어하기/삭제/검색)

**백엔드 (이미 대부분 존재)**:

- `GET /mobile/history` (limit·search) — 구현됨.
- `memory_service.delete_interaction(id)` — 구현됨.
- **추가 필요**: `DELETE /mobile/history/{interaction_id}` 엔드포인트만 신설.

**프론트**:

1. `chatMessages`를 `localStorage`(`gospel_chat`)에 영속화(재시작 후에도 이어짐).
2. 설정 탭에 "대화 기록" 섹션 → 로그인 시 `GET /mobile/history` 목록(질문 미리보기·시간) → 탭하여 해당 대화를 채팅으로 복원(이어하기) → 길게 눌러 삭제(`DELETE`).

## C. 말씀 하이라이트/북마크/메모 (풀스택)

**백엔드**:

- 모델 `VerseAnnotation`: `id, subscriber_id(FK), book, chapter, verse, color, note, created_at`.
- 엔드포인트(`mobile.py`): `GET /mobile/annotations`(본인 목록) · `POST /mobile/annotations`(등록/수정) · `DELETE /mobile/annotations/{id}`.
- 게스트도 기기단위로 쓸 수 있도록 `subscriber_id` 대신 `guestId` 낙인 허용(선택) → 우선은 로그인 기준, 게스트는 로컬 저장.

**프론트**:

1. 성경 본문 절을 **길게 누르면** 액션시트(하이라이트 색 4종 / 북마크 / 메모) 표시.
2. 하이라이트된 절은 배경색으로 표시(재진입 시 유지).
3. 설정 탭에 "말씀 메모/하이라이트" 모음(절 참조+메모) → 삭제 가능.

## D. 말씀 공유 이미지 카드

**프론트 (백엔드 불필요)**:

- `<canvas>`로 말씀 카드 생성: 절 텍스트 + 참조(요한복음 3:16) + 배경색/폰트 선택.
- `toDataURL()` → 다운로드 + `navigator.share`(파일) + 클립보드 복사.
- 성경 절과 AI 답변에서 공유 진입점 제공.
