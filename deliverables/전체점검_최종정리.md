## ⚠️ 의사결정/입력 필요 (임의 수정 불가 — 정확한 값 필요)

| # | 항목 | 필요한 결정/값 |
|---|------|----------------|
| D1 | 🔴 APK API 주소(`make-apk.bat`의 `127.0.0.1:8000`) | 실제 백엔드 HTTPS 도메인 (예: `https://api.flowai.hk`) + `.env.mobile` 생성 |
| D2 | 🔴 `PORTONE_CHANNEL_KEY` 비어서 결제 503 | PortOne 콘솔에서 채널키 발급값 |
| D3 | 🔴 `PORTONE_WEBHOOK_SECRET` 비어서 검증 생략 | PortOne 웹훅 시크릿값 |
| D4 | LLM primary 모순 (`LLM_PROVIDER=tencent` vs `LLM_FALLBACK_CHAIN=nvidia,...`) | 주 모델 선택: `nvidia`(0.48s) 권장 vs `tencent`(78s reasoning) |
| D5 | `DOCS_ENABLED=true` (API 스키마 노출) | 배포 환경이 prod인지 dev인지 |
| D6 | 로그인 상태 불일치(토큰 메모리-only, 재시작 후 "로그인 표시/미인증") | 세션 로그인 유지 vs 영속 로그인(보안저장소) |
| D7 | 런처 아이콘 기본 Capacitor 템플릿 | 브랜드 아이콘 이미지 파일 |
| D8 | `LANGFUSE_ENABLED=false`인데 키 잔존 | 사용 여부 (안 쓰면 키 제거) |

위 항목은 **비밀값·브랜드 자산·운영 정책**이 걸려 있어 임의로 값을 넣으면 오히려 하드코딩/오탐이 되므로 수정하지 않았습니다. 값만 주시면 바로 반영합니다.

## ❌ 오탐 정정 (더블체크 결과)

1. **".env 가 git에 커밋됨" → 오탐**: `git ls-files`의 exit-code 특성 때문에 오판했으나, 실제 `.env`는 HEAD·인덱스·이력 모두에 없고 gitignore 정상. 시크릿 유출 아님.
2. **"reranker 기본 none" → 정정**: config 기본값은 `none`이지만 `.env`의 `RERANKER=bge_m3`가 오버라이드해 **실제 활성**.
3. **`onclick:`(소문자) 이벤트 미동작 → 오탐**: `dom.js`가 `slice(2).toLowerCase()`로 정규화해 정상 동작.

## 검증 한계 (정직 고지)

- **Java/Android 변경(13·17)은 gradle 컴파일로 최종 확인 필요** — 이 환경에서는 `assembleRelease`를 실행하지 않았습니다(빌드 시간/샌드박스 제약). 문법은 표준 Android 패턴(`ActivityCompat.requestPermissions` + `POST_NOTIFICATIONS`)으로 작성.
- APK API 주소·결제 채널키 등은 실제 값이 없어 검증 대상에서 제외.
