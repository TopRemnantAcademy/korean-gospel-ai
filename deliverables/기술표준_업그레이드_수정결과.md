## 2. 외부 인프라/자격증명이 필요한 항목 (임의 값 금지 — 시행 지침만)

> 이 항목들은 **실제 인프라(DB 서버, IdP, Redis 등)와 자격증명 없이는 수정이 불가능**하며, 값을 지어내면 하루시네이션이 됩니다. 각 항목에 정확한 대상 파일·키·절차를 제시합니다.

### A. SQLite → PostgreSQL (데이터 계층)
- **현재**: `db.py:50` `sqlite:///.gospel.db` 기본(풀 튜닝은 이미 적용됨).
- **필요 값**: `DATABASE_URL=postgresql+psycopg://<user>:<pw>@<host>:5432/gospel`
- **절차**:
  1. `backend/app/db.py` — `create_engine`은 이미 `DATABASE_URL` 우선이므로 값만 주입.
  2. Async 전환(선택): `asyncpg`/`psycopg` async 엔진 + `AsyncSession` 도입, `chat.py`의 sync 쿼리 → async.
  3. `alembic upgrade head` 실행(현재 `db.py`의 `create_all`·마이그레이션 드리프트는 별도 정리 필요 — 기존 메모 참조).
- **주의**: JSONB/파티션/연결풀 튜닝이 선행돼야 안전(기존 메모에 기술).

### B. 커스텀 HMAC 토큰 → OAuth2/OIDC + JWT (보안)
- **현재**: `api/auth.py:69` "의존성 0" HMAC 서명 토큰, `get_current_user`(164)가 Bearer 파싱.
- **필요 값**: IdP(OAuth2/OIDC)의 `client_id`/`client_secret`/`issuer_url`.
- **절차**: `auth.py`에 `python-jose`/`PyJWT` + `Authlib` 도입, `/auth/login` → Authorization Code + PKCE, refresh token rotation 추가. Google 로그인은 이미 `oauth2.googleapis.com/tokeninfo`(506) 참조 중.

### C. 프로세스 로컬 캐시/rate limit → Redis (인프라)
- **현재**: FAQ/임베딩/검색 캐시 모두 프로세스 로컬, rate limit 인메모리(`redis_url=None`).
- **필요 값**: `REDIS_URL=redis://<host>:6379/0`
- **절차**: `rate_limit.py`는 이미 `_get_redis()`가 준비돼 있어 `REDIS_URL` 주입만으로 분산 rate limit 활성화. FAQ/임베딩 캐시의 Redis화는 별도 작업(선택).

### D. `.env` 평문 시크릿 → Secrets Manager (보안)
- **현재**: `.env`에 시크릿 14개 평문(단 gitignore 정상).
- **필요**: Vault/KMS/클라우드 시크릿 백엔드 + 주입 메커니즘.
- **절차**: 배포 시 시크릿을 env 주입(CI/CD 시크릿)으로 전환하고 `.env`는 로컬 개발 전용으로 격리.

### E. embedded Qdrant → server-mode (벡터/검색)
- **현재**: `QDRANT_URL=local:./.qdrant_local`(단일 프로세스 락).
- **필요 값**: `QDRANT_URL=http://<host>:6333` + `QDRANT_API_KEY`.
- **절차**: Qdrant 서버 기동 후 env 주입(prod에선 embedded가 fail-closed — 이미 가드 존재, `vector_store.py:240`).

### F. 관측성 (Prometheus/OTel)
- **현재**: 커스텀 로그+JSONL 트레이스, `/metrics` 없음.
- **절차**: `prometheus-client` 추가 + `/metrics` 엔드포인트 + Grafana 대시보드. OTel은 커스텀 트레이스(`tracing.py`)를 교체하는 별도 프로젝트.

### G. API 버저닝 (`/api/v1`)
- **현재**: 라우터 prefix가 `/chat`·`/admin` 등으로 무버저닝.
- **절차**: `main.py`의 `include_router`에 `prefix="/api/v1"` 추가(**모든 클라이언트 경로가 바뀌는 breaking change** → 모바일/Streamlit/관리자와 동시 배포 필요). 안전하게는 `/api/v1`과 기존 경로를 병행 마운트 후 점진 이전.

## 3. 정직 고지 (잔여 한계)
- **FAQ 정규화의 조사 부분 문자열 훼손**: `_JOSA_RE`가 "도"(그리스도→그리스)·"의"(주의→주) 등을 단어 내부에서도 제거하는 잔여 문제가 있습니다. 완전 해결은 Kiwi 형태소 기반 조사 제거가 필요하나, FAQ 핫패스에 Kiwi(~ms)를 태우는 성능 트레이드오프가 있어 이번엔 "의문사·지시어 제거"만 수정했습니다. 필요 시 후속으로 진행 가능.
- Java/Android(gradle 빌드)와 실제 DB 마이그레이션은 이 환경에서 미실행 — 표준 패턴으로 작성했음을 명시.
- PostgreSQL/Redis/OAuth2/Secrets/K8s/서버모드Qdrant/Prometheus는 **실제 인프라·자격증명이 있어야** 완결됩니다. 값을 주시면 각 항목을 즉시 반영하겠습니다.
