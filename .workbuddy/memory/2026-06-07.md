## `extraction_service.py` 재수정 — 4-Pass 영어 제거
- `_strip_english()` 전면 재작성
  - Pass 1: 괄호 영어 제거 — "사랑(love)은" → "사랑은" (한국어만 보존)
  - Pass 2: 줄 단위 — 영문 비율 70% 초과 시 줄 전체 삭제
  - Pass 3: 단어 단위 — 라틴 알파벳 연속 제거 (verse ref는 숫자만 남김)
  - Pass 4: 문법 cleanup — 고아 조사("하나님의 는"→"하나님의"), 이중 공백
- 파이프라인 순서 변경: 영어 제거를 Stage 2(가장 먼저)로 이동
- `_score()`에서 한글 비율 감점 로직 완전 삭제
